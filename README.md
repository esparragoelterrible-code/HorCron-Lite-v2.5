# HorCron Lite v2.5

Aplicación de escritorio ligera y modular desarrollada en Python utilizando CustomTkinter y persistencia en JSON para la gestión y organización de horarios con gestión tipo cronograma.

## Características
- Interfaz gráfica moderna y limpia.
- Almacenamiento local seguro basado en JSON.
- Organización dinámica tipo horario y cronograma con notas por grilla.
- División marcada por colores de tareas variadas y creación de categorías.
- Capacidad de crear y tener diferentes horarios con rutinas distintas según el propósito al mismo tiempo.
- Sistema modular de gestión de tareas y horarios.
- Sistema de exportación en formato PDF y ICS.
